## ✨ Features

- **Spatial UI Design** — Inspired by Apple Vision Pro, featuring depth, fresnel edges, colored ambient shadows, and specular highlights.
- **Interactive Orbit Constellation** — A custom Canvas API-driven rotating tech stack with real brand logos.
- **Dynamic Projects Showcase** — Carousel with generated art previews, smooth transitions, and detailed modals.
- **Working Contact Form** — Integrated with Vercel Serverless Functions and Nodemailer (Gmail SMTP).
- **Theme Toggle** — Seamless dark/light mode switch with native `View Transitions` API.
- **Custom Cursor & Particles** — Interactive background particles and magnetic buttons.
- **Fully Responsive** — Optimized layouts for mobile, tablet, and desktop.
