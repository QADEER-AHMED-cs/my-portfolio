# Qadeer Ahmed - Portfolio (React + Vite + Framer Motion)

## Run locally
npm install
npm run dev        # http://localhost:5173 (site only, contact form needs /api)

## Test the contact form locally
Copy .env.example to .env, fill the values, then:
npx vercel dev

## Deploy
Push to GitHub, import the repo in Vercel (Framework: Vite), add the 3 env vars
from .env.example in Project Settings > Environment Variables, then Redeploy.
